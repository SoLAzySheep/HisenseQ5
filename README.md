# Hisense Q5 屏幕校色

[简体中文说明](README.zh-CN.md) · [English guide](README.en.md)

面向已获取 Root 权限的 Hisense Q5（HITV105C / T610）的屏幕校色工具。它控制 Q5 面板 DPU 参数和 Android 系统饱和度，并提供可拖动的悬浮面板。

本项目目前只在 Hisense Q5 HITV105C、Android 10、`dpu-r4p0` 上验证。其他设备和固件未验证，面板接口会检查设备指纹后再写入。

---

A display calibration tool for rooted Hisense Q5 (HITV105C / T610) tablets. It controls panel DPU parameters and Android system saturation, with a movable floating panel.

The current verified target is the Hisense Q5 HITV105C running Android 10 with `dpu-r4p0`. Other models and firmware versions are unverified; panel writes are guarded by a device fingerprint check.

See the [English guide](README.en.md) or the [Simplified Chinese guide](README.zh-CN.md) for features, requirements, device limits, and build instructions.
